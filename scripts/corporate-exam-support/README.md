# 법인세 5개년 기출 보강

기준일은 2026-11-01, 대상은 2021~2025년 법인세 50문항이다. 원문의 날짜·금액을 보존하면서 기준일 규정을 적용하는 학습 자료이며 과거 신고세액을 다시 계산하는 자료가 아니다.

- `originals-2021.json`: 공식 시험지의 원문 및 당시 최종정답. 원문 PDF·정답 HWP와 미리보기는 학습 페이지에서 연결한다.
- `exam-2021.json`: 현행법 학습문장, 계산 과정, 본문 연결. 문제 자료와 숨겨지는 답·해설을 분리한다.
- `additions.json`: 출제된 조건·산식만 추가한다. 법령과 교재·기본통칙의 출처를 구분한다.
- `review.json`: 50문항의 본문 연결과 엄격한 근거 충족 판정. 전체 50문항을 분모에 남긴다.
- `validation-2022-2025.json`: 기존 40문항의 점검 기록과 당시 커밋. 기존 일반 규칙·기출·회독 카드가 보존되는지 추가 시 대조했다.
- `validation-2021.json`: 정답·기출 해설을 제외하고 문제와 연결 본문만 제공한 독립 풀이 기록. 64번은 이 검토 후 입력 항목과 해설을 조건부로 명확히 했다.

엄격한 본문 근거 충족은 42/50(84%)이다. 재구성한 2021-62·67, 추가 전제가 필요한 2021-64·2022-65·2023-66·2024-65·2025-61, 원시험 모두정답 및 현행 보기 불일치가 있는 2025-64는 분모에 포함하되 충족 수에서는 제외한다. 이는 학습자의 실제 정답률 측정이나 보장이 아니다.

`jsdom`과 `yaml`을 사용할 수 있는 Node 환경에서 저장소 루트를 기준으로 실행한다.

```sh
node scripts/corporate-exam-support/build.cjs
node scripts/corporate-exam-support/check.cjs
```

빌드는 기존 교재 순서·단원 ID·읽기 이력 키를 유지하고, 기출의 쌍방향 연결 및 목차·대조표·회독 파일을 생성한다. 기존 4개년 126장은 그대로 유지한다. 전체 파일은 156장이고, 기존 사용자의 중복 가져오기를 피하기 위한 2021년 추가 파일은 30장이다.

화면 검증은 360px 다크 모드와 1280px 라이트 모드에서 수행한다. 새 25개 O·X의 접힘/펼침, 5개 계산의 입력/초기화, AI 힌트의 정답 비노출과 선택한 답만 포함, PDF·최종정답 미리보기, 본문 펼침과 AI 문맥, 문제만 풀기, 모바일 가로 넘침을 확인한다.
