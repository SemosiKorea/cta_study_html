# 소득세 도식형 압축노트

교재 순서에 따른 10편 175개 항목을 작성 데이터로 관리합니다. 법인세 개편과 같은 화면 형식을 사용하며, 기존 판단 기준일 2026.11.1.과 2027 개정 부록을 유지합니다.

## 작성 원칙

- 첫 화면은 짧은 이해 설명 → 도표의 법정 조건·숫자·기한 → 직접 근거 순서입니다.
- 대체 계산방법은 하나의 단계 안에서 `branches`로 나눕니다. 순차 계산에만 `steps`를 사용합니다.
- 유형별 비교는 `compare` 또는 `matrix`, 사건별 기한은 `timeline`, 실제 이분법 판정은 `decision`으로 표현합니다.
- 기존 본문·조문 발췌·상세 설명은 `세부 요건·사례 더 보기`에 보존합니다.
- 실제 기출, 예상 선지, 회독 YAML, 읽기 이력 키, 2027 개정 부록을 변경하지 않습니다.

## 생성과 검증

작성 파일은 `part01.json`, `part02-03.json`, `part04-06.json`, `part07-10.json`입니다. `file`과 `id`를 함께 식별자로 사용합니다.

```sh
node scripts/income-visual-notes/build.cjs
node scripts/income-visual-notes/check.cjs
node scripts/income-visual-notes/ui-check.cjs
```

`jsdom`과 `playwright`가 필요합니다. 별도 의존성 디렉터리를 사용하면 `NODE_PATH`로 경로를 전달합니다. UI 검사는 설치된 Chrome을 사용합니다. 공개 사이트 URL을 인수로 추가하면 배포 후 같은 검사를 실행합니다.

정적 검사는 개편 전 커밋 `91c30af5c1d080055899680153c5482a47756e43`과 원문·선지·학습 키·기출·덱·부록을 대조하고 로컬 경로와 앵커를 확인합니다. UI 검사는 360px 다크 / 1280px 라이트에서 10편의 넘침, 상세 펼치기, AI 전달 범위, 문제만 풀기, 출처 미리보기, 기존 로컬 학습 이력 표시와 목차 이동을 확인합니다. 실제 모바일 기기에서의 검증은 아닙니다.
