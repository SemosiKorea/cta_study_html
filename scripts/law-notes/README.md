# 법조문 기반 학습 노트

- `basic/content.json`, `collection/content.json`: 2026.11.1. 기준 법률·시행령·시행규칙의 판단 항목, 발췌·설명·조건 비교, 창작 OX.
- 각 과목 `exam-data.json`: 첨부 시험지의 원문·공통 전제와 기준일 판정. 원문을 현행 문장으로 덮어쓰지 않는다.
- `node scripts/law-notes/build.cjs`: HTML, 법조문/기출 YAML, 읽기 단원 목록 생성. 기존 과목 단원 키는 유지한다.
- `node scripts/law-notes/check.cjs`: jsdom 설치 환경에서 구조·기출 수·근거·내부 링크·YAML 형식을 검증한다.

법령을 갱신할 때는 출처의 시행일과 적용례를 먼저 확인하고 판정·설명·예상 선지를 함께 갱신한다. 기준일 뒤 시행 개정은 appendix로 구분한다. 조문을 발췌했으면 quote에 원문을, lead/details에 학습용 설명을 둔다. 기출의 OX는 '옳은 번호'가 아니라 개별 명제의 진위를 뜻한다. 명사구·숫자 빈칸형은 공통 판단 전제가 필수다.

배포 전 데스크톱과 모바일 다크모드에서 읽기/문제 모드, 정답 가림, 원문 미리보기, 본문 복귀, 읽기 이력, AI 질문의 정답 비노출을 확인한다. 법적 정확성 검토를 구조 테스트로 대신하지 않는다.

사용자가 확정한 보류 처리: 2024년 국세징수법 47번 ⑤만 판정 보류로 표시하고 회독 OX 카드에서 제외한다. 같은 문항의 ①~④는 유지한다. 이 정책은 check.cjs에서 별도로 검증한다.
