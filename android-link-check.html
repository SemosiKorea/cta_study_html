어떤 링크에서 앱이 계속 열려 있나요?

이 페이지를 Chrome 또는 삼성 인터넷에서 여세요. 같은 브라우저에서 버튼을 누른 뒤 화면 전환이 끝나면 어디에 머무는지 확인하세요. 프로젝트 ID 없이 /g 열기(H) · 프로젝트 경로 비교(C·G) · 도메인 비교(D~F)

H. 프로젝트 ID 없이 /g 열기

C와 G에서 같은 프로젝트가 열렸다면 H를 눌러 보세요. 프로젝트 주소를 입력할 필요가 없습니다.

H · /g로 ChatGPT 앱 열기

앱이 마지막 화면을 다시 보여 주는지 구별하려면 먼저 ChatGPT 앱에 이전 대화 하나를 열어 두세요. 브라우저로 돌아와 H를 눌렀을 때 앱에 프로젝트 이름도 이전 메시지도 없는 새 대화가 열리면 성공입니다.

A. 일반 홈

현재 세법 사이트의 ‘ChatGPT 앱’ 버튼과 같은 주소입니다.

A · 일반 홈으로 앱 열기

B. /project

A와 같은 방식으로 앱을 요청하고 주소의 경로만 /project로 바꿉니다.

B · /project로 앱 열기

C·G. 실제 프로젝트 경로 비교

앱에서 열렸던 프로젝트 주소 전체를 붙여넣으세요. 주소는 이 탭에서 링크를 만드는 데만 사용합니다.

C · 지정한 프로젝트로 앱 열기

G · 끝의 /project만 빼고 앱 열기

C로 앱이 열렸다면 G만 눌러 보세요. 화면 전환이 끝난 뒤 프로젝트 이름이 없는 일반 새 대화에 머무르면 성공입니다. 프로젝트 화면, 웹, Google Play 중 하나가 열리면 그 화면을 결과로 보세요.

D~F. 도메인만 바꾸기

A와 같은 일반 홈 경로와 같은 ChatGPT 앱을 지정합니다. D부터 눌러 보세요. 앱의 일반 새 대화 화면에 머무르면 나머지는 시험할 필요가 없습니다.

D · app.chatgpt.com

E · chat.openai.com

F · chat.com

결과는 버튼 문자와 마지막 화면으로 기록하세요. 예를 들어 ‘D · 앱의 일반 새 대화’, ‘E · 앱이 잠깐 열렸다가 웹으로 이동’, ‘F · 다운로드 화면’처럼 적으면 됩니다. 접근 인증 화면이 뜨면 그 시점에서 시험을 끝내세요.
